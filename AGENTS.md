# Project instructions

- Read `README.md` before changing the application.
- `README.md` is the canonical description of the app's current state for users and future contributors. Update it in the same change whenever application code, UI, dependencies, configuration, or behavior changes. Keep it factual and focused on what the app does now; do not turn it into a changelog.
- Keep setup, permissions, data handling, and known limitations in the README accurate when they are affected by a change.
